TVICameraSourceOrientationDelegate

Objective-C

@protocol TVICameraSourceOrientationDelegate <NSObject>

Swift

protocol TVICameraSourceOrientationDelegate : NSObjectProtocol

@brief A protocol which allows TVICameraSourceOrientationTracker to notify interested parties about orientation changes.

  • -trackerOrientationDidChange:

    Deprecated

    Use the trackerRotationAngleDidChange:rotationAngle: method instead.

    @brief A callback that should be fired whenever the tracker’s orientation changes.

    @discussion This method should be called on the main thread. Calling the delegate causes TVICameraSource to enqueue an update task on its internal AVCaptureVideoDataOutput queue, and to update the TVICameraPreviewView orientation, if present. This method is deprecated in favor of trackerRotationAngleDidChange.

    Declaration

    Objective-C

    - (void)trackerOrientationDidChange:(AVCaptureVideoOrientation)orientation;

    Swift

    optional func trackerOrientationDidChange(_ orientation: AVCaptureVideoOrientation)

    Parameters

    orientation

    The updated orientation value.
  • -trackerRotationAngleDidChange:

    @brief A callback that should be fired whenever the tracker’s rotation angle changes.

    @discussion This method should be called on the main thread. Calling the delegate causes TVICameraSource to enqueue an update task on its internal AVCaptureVideoDataOutput queue, and to update the TVICameraPreviewView orientation, if present.

    Declaration

    Objective-C

    - (void)trackerRotationAngleDidChange:(CGFloat)rotationAngle;

    Swift
